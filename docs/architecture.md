# 프로젝트 구조

이 문서는 프로젝트의 코드 구조와 실행 흐름을 정리합니다.

## 현재 구조

```text
.
├── README.md
├── docs
└── tools
```

## 주요 영역

- `README.md`: 프로젝트 진입점입니다.
- `docs/`: 문서와 상태 데이터를 관리합니다.
- `docs/data/project-status.yaml`: 프로젝트 상태 관리 원본입니다.
- `docs/DASHBOARD.html`: 자동 생성되는 프로젝트 대시보드입니다.
- `tools/generate_dashboard.py`: 대시보드 생성 도구입니다.
