# 개발 메모

이 폴더는 개발 중 나온 아이디어, 결정사항, 임시 메모를 보관하는 공간입니다.

템플릿 저장소에 반영할 만한 범용 개선 사항은 [template-feedback.md](template-feedback.md)에 기록합니다.

정리된 내용은 필요에 따라 아래 문서로 옮깁니다.

- `docs/data/project-status.yaml`
- `docs/architecture.md`
- `docs/setup.md`

메모 파일을 추가할 때는 날짜나 주제가 드러나는 이름을 사용합니다.

예시:

```text
2026-06-02-planning-notes.md
feature-idea.md
```
