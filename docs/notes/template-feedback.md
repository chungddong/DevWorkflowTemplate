# 템플릿 개선 피드백

이 문서는 현재 프로젝트를 진행하면서 템플릿 저장소에 반영할 만한 개선 사항을 기록합니다.

## 작성 기준

- 여러 프로젝트에서 반복적으로 유용할 내용만 기록합니다.
- 프로젝트 고유 요구사항은 기록하지 않습니다.
- 구조 변경이 있었다면 변경 전과 변경 후를 함께 적습니다.
- 템플릿 저장소에 반영할 때 참고할 수 있도록 이유와 기대 효과를 적습니다.
- 이미 템플릿 저장소에 반영된 항목은 상태를 `반영 완료`로 변경합니다.

## 상태 값

- `제안`: 템플릿에 반영할지 검토가 필요한 상태
- `검토 중`: 템플릿 저장소에서 반영 여부를 검토 중인 상태
- `반영 완료`: 템플릿 저장소에 반영된 상태
- `보류`: 범용성이 부족하거나 아직 판단하기 어려운 상태

## 피드백 항목

아래 형식으로 항목을 추가합니다.

````md
### YYYY-MM-DD: 개선 제목

상태: 제안

배경:

- 왜 이 개선이 필요한지 작성합니다.

변경 내용:

- 어떤 파일이나 구조를 변경했는지 작성합니다.

변경 전:

```text
변경 전 구조를 작성합니다.
```

변경 후:

```text
변경 후 구조를 작성합니다.
```

기대 효과:

- 템플릿에 반영했을 때 얻는 효과를 작성합니다.

템플릿 저장소 반영 제안:

- 템플릿 저장소에 어떻게 반영하면 좋을지 작성합니다.
````
